# redirect-onlyfans2# Redirection OnlyFans avec Vercel

## ✅ AVANT DE DÉPLOYER
1. Ouvrez `api/redirect.js`
2. Remplacez `https://onlyfans.com/votre_username` par votre VRAI lien OnlyFans
3. Sauvegardez

## 🚀 DÉPLOYER SUR VERCEL (15 min)

### Étape 1 : Créer un compte GitHub
- Allez sur github.com
- Créez un compte (gratuit)
- Confirmez votre email

### Étape 2 : Créer un repo GitHub
- Cliquez "+" en haut à droite → "New repository"
- Nommez-le "redirect-onlyfans"
- Cochez "Add a README file"
- Cliquez "Create repository"

### Étape 3 : Uploader les fichiers
Dans votre nouveau repo GitHub :
- Cliquez "Upload files"
- Glissez-déposez TOUS les fichiers de votre dossier `redirect-of`
- Cliquez "Commit changes"

### Étape 4 : Déployer sur Vercel
1. Allez sur vercel.com
2. Cliquez "Sign up" → "Continue with GitHub"
3. Autorisez Vercel
4. Cliquez "Import Project" 
5. Sélectionnez "redirect-onlyfans"
6. Cliquez "Deploy"
7. ⏳ Attendez 1-2 minutes...
8. Vous obtenez une URL type : `https://redirect-onlyfans.vercel.app`

### Étape 5 : Mettre dans Instagram
L'URL à utiliser est : `https://redirect-onlyfans.vercel.app/api/redirect`

Collez-la dans votre bio Instagram ! 🎉
